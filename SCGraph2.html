SCGraph2 Help

Interface layout

The Data Input module always appears immediately below the Graph. On wide screens, Graph Controls and Analysis appear in a right-hand column; on narrower screens they move below Data Input. Every module remains independently collapsible. The scrollable region is the module content area itself: place the pointer over the open panel and use the mouse wheel/trackpad, or drag its scrollbar, when the contents exceed the panel height.

Data entry

Enter one series per line using Label: values. Commas separate observations and a vertical bar creates a phase boundary. Session numbers continue across phases.

Sniffing: 2,4,5,2|6,7,4,5

Plain adjacent series lines are plotted together in the same graph. All series use the same phase-name list and must have the same number of phases.

Multiple graphs and multiple-baseline layouts

Use a separator on its own line between series. A minus sign (-) starts a new independent graph panel. SCGraph2 supports up to three graph panels.

Accuracy: 2,3,4|7,8,9 - Rate: 10,11,12|15,17,18 - Errors: 8,7,6|3,2,1

Use a plus sign (+) to create a multiple-baseline group. Each joined series receives its own vertically stacked tier, but the tiers use one common horizontal Session timeline. Their phase changes may occur at different sessions.

Student A: 2,3,3|6,7,8 + Student B: 2,2,3,3,4|6,7,8 + Student C: 1,2,2,3,3,4,4|7,8,9

You can combine the syntax: - separates graph panels; + creates shared-timeline tiers inside a graph panel. Plain adjacent series inside the same tier are overlaid and therefore must use matching phase-boundary locations.

In a + multiple-baseline display, corresponding phase-change lines are connected across adjacent tiers. This visually links the same phase transition (for example, Baseline → Intervention) even when its onset is staggered across tiers. Independent graph panels separated by - are not connected.

Each multiple-baseline tier has its own horizontal axis line and Session tick marks so the common timeline is visible at every tier. Session numbers are printed only on the bottom tier.

Analyzing one series when several are graphed

Analyses are always performed on one specified series at a time, regardless of which graph panel or multiple-baseline tier contains it. Use the Series to analyze menu, or include the series in the analysis command.

Trend, series=2, 1
T-U, series=Accuracy, 1, 2

Series may be referenced by its number (1–4) or by its exact label. Natural-language requests such as “perform Tau-U on series Accuracy, phases 1 and 2” are also accepted. With only one series, SCGraph2 selects it automatically. With multiple series, if neither the selector nor the command identifies a series, SCGraph2 asks you to choose one rather than silently analyzing Series 1.

Ghosting observations

Ghosting is encoded inside the data stream. Surround one numerical value with parentheses.

Sniffing: 2,4,(5),2|6,7,4,5

Here, Session 3 remains at Session 3 but is displayed in gray, omitted from active connecting lines, and excluded from visual and quantitative calculations. Parentheses do not consume or change session numbers. Remove the parentheses to restore the point, or use Un-ghost all points.

Phase boundaries and graph conventions

  • Each | creates a thin solid vertical phase line halfway between the adjoining sessions.
  • Observations are connected only within a phase; lines never cross a phase boundary.
  • Ghosted observations break the active connecting line rather than being bridged.
  • Phase names can be entered in the Data Input or Graph Controls module.

Visual analysis

Use the Analysis module or type commands such as:

Level, 1 IQRLevel, 1 Trend, 1 IQRTrend, 1 whiskerTrend, 1 whisker-Level, 1

Level uses the active phase median. Trend uses a Theil–Sen estimator and displays the fitted trend line only. IQRTrend adds the residual Q1/Q3 trend band. The separate Trend + 0.3 IQR analysis adds symmetric bounds at trend ± 0.30 × residual IQR and performs the phase-comparison binomial test. IQR and whisker variants are based on active observations only.

Quantitative analysis

PND, 1, 2 M-W, 1, 2 TrendBinomial, 1, 2 T-U, 1, 2

The first phase is the control/comparison phase and the second is the treatment/comparison phase. TrendBinomial (the “Trend + 0.3 IQR” button) fits the Theil–Sen trend in the first phase, computes its residual IQR, projects parallel bounds at trend ± 0.30 × IQR, and tests how many second-phase observations cross the improvement-side boundary. Counts above, below, and within the envelope are reported. The legacy command binomial, 1, 2 remains accepted as an alias. Ghosted observations are excluded. Use the improvement-direction control when lower values represent improvement.

Natural-language graph commands

place level lines in both phases place trend lines in both phases set y-axis 0 to 20 hide gridlines title: Reading Fluency

Graph changes modify only the requested display feature. Analysis overlays can be cleared without altering the data.

Save and load SCGraph2 state

Save State opens a filename dialog, then downloads a versioned .json file containing the current SCGraph2 session: the complete data stream (including +, -, phase boundaries, and parenthesized ghost points), graph controls, phase labels, analysis settings, the selected analysis series, current overlays/results, commands, notes, and which accordion modules are open.

Load State restores a previously saved SCGraph2 JSON session. The data are reparsed and verified before saved analyses and overlays are restored.

Export

Use Export SVG for a scalable publication-quality figure or Export PNG for a high-resolution raster image. Processing occurs locally in the HTML file.
