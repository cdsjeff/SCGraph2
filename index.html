Starting SCGraph2

1. Enter the data

Enter one labeled series per line. Use | for phase changes and parentheses to ghost an observation without changing its session position.

Accuracy: 2,4,(5),3|7,8,9

2. Choose the graph layout in the data stream

  • Adjacent series lines overlay series in the same graph.
  • + on its own line creates vertically stacked multiple-baseline tiers on one shared Session timeline. Tiers may have different numbers of phases; SCGraph2 connects corresponding available phase-change lines by order (first-to-first, second-to-second, etc.). Extra phase lines remain unconnected.
  • - on its own line starts a new independent graph panel; up to three graphs are supported. Independent graphs may have different numbers of phases.
Student A: 2,3,3|6,7,8 + Student B: 2,2,3,4,4|6,7,8 - Accuracy: 40,45,50|70,78,85

3. Load and format the graph

Select Load & Graph Data. In Graph Controls, choose the graph to edit. Each independent graph can have its own graph label, Y-axis label, vertical range, tick interval, and autoscale method.

Autoscale choices include the single-case rules for nonnegative/unbounded measures, known measurement bounds, measures allowing negative values, and the original SCGraph heuristic. The current effective scale is shown in Graph Controls.

4. Add goal lines when needed

Under Graph Controls → Goal Lines, choose the series/tier, phase span, and Y value. Goal lines are retained independently of analysis overlays and are saved in the JSON state.

5. Run an analysis

At the top of the Analysis panel, choose Graph to analyze first and then Series to analyze. The two selectors appear above the analysis buttons so the current target remains visible before you turn analyses on or off. Visual analyses include Level, Trend, IQR variants, and Trend + 0.3 IQR. Quantitative analyses include PND, Mann–Whitney, Trend + 0.3 IQR binomial, and Tau-U.

6. Choose a save location, then save or export

Use Save Location to open the browser folder chooser and remember a folder when SCGraph2 is running as a top-level secure page in a supporting browser. Embedded previews cannot open persistent directory pickers; SCGraph2 therefore hides the folder-picker action in that context and Save State, Export SVG, and Export PNG automatically use normal browser downloads. Load State restores a saved JSON session from any location you select.

Tip: Set the analysis target with the darker Graph to analyze and Series to analyze selectors at the top of the Analysis panel. Analysis buttons are independent toggles: click once to add that analysis and click again to remove only that analysis. Active buttons are highlighted. Data Input stays directly below the graph. On wide screens, Graph Controls and Analysis split the right column equally when both are open; closing one lets the other expand. Use Help for the full command and analysis reference.

SCGraph2 Help

Start Up

For the condensed workflow, use the Start Up button in the header. The full reference below documents data syntax, multi-graph and multiple-baseline layouts, independent Y-axis controls and autoscaling, goal lines, analyses, JSON state files, and export.

Interface layout

The Data Input module always appears immediately below the Graph. On wide screens, Graph Controls and Analysis share the right-hand column dynamically: when both are open they divide the available vertical space equally; when one is closed, the other expands into the remaining space. On narrower screens they move below Data Input. Every module remains independently collapsible, and each open module body scrolls internally when its contents exceed the available panel height.

Data entry

Enter one series per line using Label: values. Commas separate observations and a vertical bar creates a phase boundary. Session numbers continue across phases.

Sniffing: 2,4,5,2|6,7,4,5

Plain adjacent series lines are plotted together in the same graph. Series within the same graph must use the same number of phases; independent graphs separated by - may use different phase counts. The global phase-name list is applied by phase number to each graph.

Multiple graphs and multiple-baseline layouts

Use a separator on its own line between series. A minus sign (-) starts a new independent graph panel. SCGraph2 supports up to three graph panels, and each independent graph may have its own number of phases.

Accuracy: 2,3,4|7,8,9 - Rate: 10,11,12|15,17,18 - Errors: 8,7,6|3,2,1

Use a plus sign (+) to create a multiple-baseline group. Each joined series receives its own vertically stacked tier, but the tiers use one common horizontal Session timeline. Their phase changes may occur at different sessions, and the tiers do not need to contain the same number of phases.

Student A: 2,3,3|6,7,8 + Student B: 2,2,3,3,4|6,7,8 + Student C: 1,2,2,3,3,4,4|7,8,9

You can combine the syntax: - separates graph panels; + creates shared-timeline tiers inside a graph panel. Plain adjacent series inside the same tier are overlaid and therefore must use matching phase-boundary locations.

In a + multiple-baseline display, corresponding phase-change lines are connected across adjacent tiers. SCGraph2 connects corresponding phase-change lines by order across adjacent tiers (first-to-first, second-to-second, and so on). If one tier contains fewer phase lines than another, only the shared available lines are connected; any additional phase lines remain unconnected. Independent graph panels separated by - are not connected.

Each multiple-baseline tier has its own horizontal axis line and Session tick marks so the common timeline is visible at every tier. Session numbers are printed only on the bottom tier.

Each graph panel created with - has its own display settings. In Graph Controls → Graph to edit, choose Graph 1, Graph 2, or Graph 3, then set that graph’s Graph label, Y-axis label, Y minimum, Y maximum, and optional Y tick interval. These settings do not change the other graph panels. Auto-scale may also be enabled independently for each graph. A + multiple-baseline structure is treated as one graph panel, so its stacked tiers share that graph’s Y-axis settings while retaining their own series/tier labels.

Auto-scale methods: Single-case — unbounded ≥ 0 starts at 0 and extends the upper axis to the next readable 1–2–5 major tick beyond the highest displayed data or goal value. Single-case — known bounds uses the full measurement range you enter in Known minimum/maximum. Single-case — allow negative values extends one readable major tick beyond both the lowest and highest displayed values. Original SCGraph heuristic preserves the earlier rule: start at 0 for nonnegative data (or pad below a negative minimum by about 5%) and add about 8% headroom above the maximum. Ghosted observations remain part of display scaling, and the single-case modes also include goal-line values so goals remain visible.

Analyzing one series when several are graphed

Analyses are always performed on one specified series at a time. The Graph to analyze and Series to analyze selectors are positioned at the top of the Analysis panel, above the analysis buttons. When multiple graph panels exist, choose the graph first and then the series/tier within that graph. A one-series graph auto-selects its series; a multiple-series or multiple-baseline graph asks you to choose the target series/tier.

Trend, series=2, 1
T-U, series=Accuracy, 1, 2

The selected Graph scopes series references, so series=2 means the second series/tier within the selected graph. A series may also be referenced by its exact label. Natural-language requests such as “perform Tau-U on series Accuracy, phases 1 and 2” use the currently selected graph as context.

Ghosting observations

Ghosting is encoded inside the data stream. Surround one numerical value with parentheses.

Sniffing: 2,4,(5),2|6,7,4,5

Here, Session 3 remains at Session 3 but is displayed in gray, omitted from active connecting lines, and excluded from visual and quantitative calculations. Parentheses do not consume or change session numbers. Remove the parentheses to restore the point, or use Un-ghost all points.

Phase boundaries and graph conventions

  • Each | creates a thin solid vertical phase line halfway between the adjoining sessions.
  • Observations are connected only within a phase; lines never cross a phase boundary.
  • Ghosted observations break the active connecting line rather than being bridged.
  • Phase names can be entered in the Data Input or Graph Controls module.

Goal lines

A goal line is a horizontal criterion line placed at a user-defined Y value. In Graph Controls → Goal Lines, choose the series or multiple-baseline tier, the start phase, the last phase the line should span, and the goal value. Set start and through phase to the same phase for a phase-specific goal, or choose a later through phase to extend one goal across multiple phases. Goal lines are graph settings rather than analysis overlays, so clearing or recomputing analyses does not remove them. Goal lines are included in saved JSON state files.

Goal, 1, 80
Goal, 1, 2, 80

The compact commands above place a goal at Y = 80 in Phase 1 only, or from Phase 1 through Phase 2, respectively, using the series/tier selected in Graph Controls.

Visual analysis

Analysis buttons toggle independently. Click a button once to add its result/overlay for the currently selected series; click the same highlighted button again to remove only that analysis. Other active analyses remain displayed.

Use the Analysis module or type commands such as:

Level, 1 IQRLevel, 1 Trend, 1 IQRTrend, 1 whiskerTrend, 1 whisker-Level, 1

Level uses the active phase median. Trend uses a Theil–Sen estimator and displays the fitted trend line only. IQRTrend adds the residual Q1/Q3 trend band. The separate Trend + 0.3 IQR analysis adds symmetric bounds at trend ± 0.30 × residual IQR and performs the phase-comparison binomial test. IQR and whisker variants are based on active observations only.

Quantitative analysis

PND, 1, 2 M-W, 1, 2 TrendBinomial, 1, 2 T-U, 1, 2

The first phase is the control/comparison phase and the second is the treatment/comparison phase. TrendBinomial (the “Trend + 0.3 IQR” button) fits the Theil–Sen trend in the first phase, computes its residual IQR, projects parallel bounds at trend ± 0.30 × IQR, and tests how many second-phase observations cross the improvement-side boundary. Counts above, below, and within the envelope are reported. The legacy command binomial, 1, 2 remains accepted as an alias. Ghosted observations are excluded. Use the improvement-direction control when lower values represent improvement.

Natural-language graph commands

place level lines in both phases place trend lines in both phases set y-axis 0 to 20 hide gridlines goal line phase 2 at 80 title: Reading Fluency

Graph changes modify only the requested display feature. Analysis overlays can be cleared without altering the data.

Save location, save state, and load state

Save Location opens the browser folder chooser directly and can remember the chosen folder when SCGraph2 is opened as a top-level HTTPS page in a browser that supports the File System Access API (notably Chrome and Edge). Browser security prevents directory pickers inside cross-origin embedded previews/iframes and in some non-secure contexts. In those situations SCGraph2 hides the unavailable folder action and automatically uses the browser's normal download mechanism instead of failing. A remembered folder can be changed or forgotten at any time and may occasionally require reauthorization.

Save State opens a filename dialog, then writes a versioned .json file to the remembered save folder when one is available; otherwise it sends the file to the browser's download location. The file contains the complete SCGraph2 session: the data stream (including +, -, phase boundaries, and parenthesized ghost points), per-graph labels, Y-axis labels, manual scales, tick intervals, autoscale methods and known bounds, goal lines, phase labels, selected analysis graph/series, analysis settings, overlays/results, commands, notes, and accordion open/closed state.

Load State restores a previously saved SCGraph2 JSON session. The data are reparsed and verified before graph-specific settings, goal lines, and saved analyses/overlays are restored. Older SCGraph2 state files are migrated when possible. Loading always uses the browser's file chooser, so a state file can be opened from any accessible location.

Export

Export SVG and Export PNG use the remembered Save Location when available and otherwise use the browser's standard download mechanism. PNG export is rendered directly from SCGraph2's graph primitives to a canvas; it does not depend on re-loading a serialized SVG image. Processing remains local in the HTML file; SCGraph2 does not upload the data or figure to a server.
